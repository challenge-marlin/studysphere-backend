# StudySphere データベーステーブル構成資料

## 1. データベース概要

- **データベース名**: `curriculum-portal`
- **文字コード**: UTF8MB4
- **照合順序**: utf8mb4_0900_ai_ci
- **エンジン**: InnoDB

## 2. 主要テーブル一覧

### 2.1 ユーザー・認証関連

#### user_accounts（ユーザー情報テーブル）
すべてのユーザー情報を管理するマスターテーブル。

| カラム名 | 型 | 説明 | 制約 |
|---|---|---|---|
| id | INT | ユーザーID（主キー） | PRIMARY KEY, AUTO_INCREMENT |
| name | VARCHAR(255) | ユーザー名（個人名または企業名） | NOT NULL |
| email | VARCHAR(255) | メールアドレス | NULL可 |
| role | TINYINT | ロール（10=マスター、9=アドミン、5=管理者、4=指導員、1=利用者） | NOT NULL |
| status | TINYINT | ステータス（1=稼働中、0=停止中） | NOT NULL, DEFAULT 1 |
| login_code | CHAR(14) | ログインコード（形式：XXXX-XXXX-XXXX） | NOT NULL, UNIQUE |
| company_id | INT | 所属企業ID | FOREIGN KEY (companies.id) |
| satellite_ids | JSON | 所属拠点ID配列（複数拠点対応） | NULL可 |
| is_remote_user | BOOLEAN | 在宅支援対象（ロール1専用） | NOT NULL, DEFAULT FALSE |
| recipient_number | VARCHAR(30) | 受給者証番号 | NULL可 |
| password_reset_required | TINYINT(1) | パスワード変更要求フラグ | NOT NULL, DEFAULT 0 |
| instructor_id | INT | 担当指導員ID（ロール1専用） | FOREIGN KEY (user_accounts.id) |

**インデックス**:
- `unique_login_code`: login_codeのユニーク制約
- `idx_satellite_ids`: satellite_ids（JSON）へのインデックス
- `idx_email`: emailへのインデックス
- `idx_instructor_id`: instructor_idへのインデックス

#### admin_credentials（管理者認証テーブル）
ロール4以上の管理者・指導員の認証情報を管理。

| カラム名 | 型 | 説明 | 制約 |
|---|---|---|---|
| id | INT | 認証ID（主キー） | PRIMARY KEY, AUTO_INCREMENT |
| user_id | INT | ユーザーID | NOT NULL, UNIQUE, FOREIGN KEY (user_accounts.id) |
| username | VARCHAR(50) | ログインID | NOT NULL, UNIQUE |
| password_hash | VARCHAR(255) | パスワードハッシュ（bcrypt） | NOT NULL |
| created_at | DATETIME | 作成日時 | DEFAULT CURRENT_TIMESTAMP |
| updated_at | DATETIME | 更新日時 | DEFAULT CURRENT_TIMESTAMP ON UPDATE |
| last_login_at | DATETIME | 最終ログイン日時 | NULL可 |

#### user_temp_passwords（利用者一時パスワード管理テーブル）
ロール1（利用者）の一時パスワードを管理。

| カラム名 | 型 | 説明 | 制約 |
|---|---|---|---|
| id | INT | 一時パスワードID | PRIMARY KEY, AUTO_INCREMENT |
| user_id | INT | ユーザーID | NOT NULL, FOREIGN KEY (user_accounts.id) |
| temp_password | VARCHAR(10) | 一時パスワード（XXXX-XXXX形式） | NOT NULL |
| issued_at | DATETIME | 発行日時 | DEFAULT CURRENT_TIMESTAMP |
| expires_at | DATETIME | 有効期限（日本時間23:59） | NOT NULL |
| is_used | TINYINT(1) | 使用済みフラグ | NOT NULL, DEFAULT 0 |
| used_at | DATETIME | 使用日時 | NULL可 |

**自動削除イベント**: `cleanup_expired_temp_passwords`（毎日0:10 JST実行）

## 4. イベントスケジューラー

MySQLのイベントスケジューラーが以下の自動削除を実行します：

1. **cleanup_expired_temp_passwords**: 毎日0:10 JST実行
   - 期限切れの一時パスワードを削除

2. **cleanup_expired_personal_messages**: 毎日0:30 JST実行
   - 60日経過した個人メッセージを削除

3. **cleanup_expired_announcements**: 毎日0:30 JST実行
   - 60日経過したアナウンスメッセージを削除

## 5. インデックス最適化

主要な検索パフォーマンス向上のため、以下のインデックスが設定されています：

- **user_lesson_progress**: user_id, lesson_id, status, completed_at
- **courses**: status, category, order_index
- **lessons**: course_id, status, order_index
- **deliverables**: user_id, lesson_id, instructor_approved, uploaded_at
- **remote_support_daily_records**: user_id, date (ユニーク)
- **exam_results**: user_id, lesson_id, test_type, exam_date
