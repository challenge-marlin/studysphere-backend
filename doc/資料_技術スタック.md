# StudySphere 技術スタック資料

## 1. システム概要

StudySphereは、就労移行支援事業所向けの学習管理システム（LMS：Learning Management System）です。階層管理に対応したWebアプリケーションで、管理者・指導員・利用者の3つの役割をサポートします。

## 2. システムアーキテクチャ

### 2.1 全体構成

```
[ユーザー]
    ↓ HTTPS
[フロントエンド] (React + Tailwind CSS)
    ↓ API通信 (HTTP/HTTPS)
[バックエンドAPI] (Node.js + Express)
    ↓ TCP接続
[MySQL データベース] (Docker Container)
    ↓ 外部サービス連携
[AWS S3] (ファイルストレージ)
[OpenAI API] (AI機能)
```

### 2.2 開発環境構成

- **OS**: Windows 10/11（開発環境）
- **コンテナ化**: Docker + Docker Compose
- **データベース**: MySQL 8.0（Dockerコンテナ）
- **バックエンド**: Node.js 20.x（Dockerコンテナまたはローカル実行）
- **フロントエンド**: React 18（ローカル実行）

## 5. セキュリティ

- **認証**: JWT（アクセストークン + リフレッシュトークン）
- **パスワード**: bcryptjsによるハッシュ化
- **CORS**: 適切なオリジン設定
- **Helmet**: HTTPヘッダーセキュリティ
- **入力検証**: Express Validator
- **レート制限**: Express Rate Limit（実装可能）

## 6. ログ・モニタリング

- **Winston**: 構造化ログ出力
- **Morgan**: HTTPリクエストログ
- **Docker Logging**: コンテナログ管理（JSON形式、ローテーション対応）

## 7. パフォーマンス最適化

- **データベース接続プール**: 接続の再利用
- **インデックス**: クエリ最適化
- **画像最適化**: Sharpによる画像リサイズ
- **ファイルストレージ**: S3による分散ストレージ

## 10. 環境変数

### バックエンド

- `DB_HOST`: データベースホスト
- `DB_PORT`: データベースポート
- `DB_USER`: データベースユーザー名
- `DB_PASSWORD`: データベースパスワード
- `DB_NAME`: データベース名
- `AWS_ACCESS_KEY_ID`: AWSアクセスキー
- `AWS_SECRET_ACCESS_KEY`: AWSシークレットキー
- `AWS_REGION`: AWSリージョン
- `AWS_S3_BUCKET`: S3バケット名
- `OPENAI_API_KEY`: OpenAI APIキー
- `NODE_ENV`: 環境（development/production）

### フロントエンド

- `REACT_APP_API_URL`: APIエンドポイント（オプション）
